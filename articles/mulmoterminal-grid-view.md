[MulmoTerminal](https://github.com/receptron/mulmoterminal) は、[Claude Code](https://claude.com/claude-code) をブラウザのターミナルで動かすツールです。`npx mulmoterminal@latest` 一発で、サーバ上の本物の PTY で `claude` が起動し、ブラウザの [xterm.js](https://xtermjs.org/) に流れてきます。

この記事では、その中でも個人的にいちばん"効く"**グリッドビュー**にフォーカスして、推し機能を5つ紹介します。ひとことで言うと **「複数の Claude Code エージェントを1画面のダッシュボードで束ねて並列運用する」** ための画面です。

```sh
npx mulmoterminal@latest
```

起動すると、**そのままグリッドが開きます**（v2.1.0 で既定になりました。URL は `/terminals`）。
1体に集中する単一ビューは **`/chat`** に独立したアドレスがあるので、そちらから始めたい人はブックマークしてください。

![グリッドビューの全景](/images/mulmoterminal-grid/01-overview.png)

## 1. 最大9分割 → タブで81枚、複数エージェントを一望

グリッドは1本のフラットなセルの並びで、**セル数に応じてレイアウトが自動で育ちます**（1 → 2 → 2×2 → 3×2 → 4×2 → 3×3）。9枚を超えると**タブ（ページ）**にあふれ、最大 **81 セッション**まで扱えます。

セルを閉じるとリストが自動で詰め直され、後ろのセルがページ境界を越えて前へ流れてきます。「AI エージェントを何体も同時に走らせて、1画面で見張る」体験がこれで成立します。

## 2. 各セルが独立した"本物"の Claude / Codex セッション

各セルはサーバ上の**本物の PTY で動く `claude`**（または `codex`）です（`-p`/headless ではなく、対話モードの CLI をそのまま TTY 経由で中継）。空セルのランチャーからは、

- ディレクトリを選んで**新規起動**
- そのディレクトリの**既存セッションを resume**
- `script.json` の**コマンドを実行**（dev server やテストをセルとして常駐）

を選べます。

![セルのランチャー](/images/mulmoterminal-grid/02-launcher.png)

しかも**表示中のページ以外もサーバ側で走り続け**、ページを戻すと再アタッチします。うっかりタブを閉じそうになると確認ダイアログ（0.6.0 の新機能）が出て、動いているセッションを守ってくれます。

:::message
**コストの話。** ここで動くのは API でも headless でもなく、いつも使う**対話モードの `claude` そのもの**です。だから使用量は **あなたの Claude プラン（Max など）の枠内**でカウントされ、トークン従量の API 課金は発生しません。**グリッドで何体並列に回しても、料金は"いつものサブスク"の中**（プランの利用上限の範囲）で収まります。
:::

## 3. git worktree 分離 — 同じリポジトリを複数エージェントで安全に並行作業

これがグリッドビューの**いちばんの推し**です。

対象ディレクトリが git リポジトリなら、セルを**使い捨ての worktree**（作業ツリーは別・`.git` は共有）で起動できます。つまり **複数エージェントが同じリポを衝突なしで同時にいじれる**。「3体のエージェントで3つの機能を並行実装 → 3つの PR」が現実的になります。

さらに、セル内で開発ループが完結します。

- ヘッダーに **ahead / dirty バッジ**（ベースブランチとの差分）
- **diff パネル**で変更ファイル＋パッチを閲覧
- **Commit**（Claude 自身に良いメッセージでコミットさせる）→ **Push** → **Open PR** までワンクリック

![worktree セルの diff と PR 操作](/images/mulmoterminal-grid/03-worktree.png)

## 4. 拡大 ↔ グリッドの行き来 — コックピット・ロスター

1つのセルを **⤢ で拡大**すると、そのセルが大画面を占有します。このとき横に出るのが **コックピット・ロスター**（既定）——**全セッションを1行ずつ並べたテキスト一覧**です。

各行が持っている情報がポイントで、

- ディレクトリ
- **AI が書いたサマリー**（いま何をしているか）
- **直近のプロンプト**（自分が何を頼んだか）
- **最新の返答**
- 状態語（running / planning / done / idle …）
- ブランチの **PR フェーズ**（draft / CI fail / changes / ready / merged …）

**行をクリックすると拡大対象が切り替わります。** 拡大したまま、残り全員の「何をして、どこまで進んだか」が文字で追える。多数を回すときの主戦場はここです。

右上の **▤ / ☰** で、ロスターと**フィルムストリップ**（従来のサムネイル列）を行き来できます。**⤡** でグリッドへ戻ります。

![ズームとフィルムストリップ](/images/mulmoterminal-grid/04-zoom.png)

各行が何行ぶん使うかは `~/.mulmoterminal/config.json` の `cockpitLines` で変えられます（既定は サマリー2 / プロンプト2 / 返答3）。**サマリーの行数を増やすと、拡大しなくても中身が読めます。**

```jsonc
{ "cockpitLines": { "summary": 4, "prompt": 2, "reply": 3 } }
```

## 5. Manual / Auto の並べ替え＋ステータス可視化で"呼び戻される"

ツールバーのトグルで並び順を切り替えられます。

- **Manual**：各セルの **◀▶** で手動並べ替え
- **Auto**：**要対応（waiting）→ アイドル → 動作中（working）** の安定ソートで、**あなたの操作待ちのセルが自動で前に浮く**

加えて、セルは**枠の色とドット**で状態を表示（青＝作業中／琥珀＝要対応）。そして **作業が終わって応答待ち（要対応）になると、音で知らせて**くれます（アテンション音）。**動的 favicon**（タブのアイコンが状態で変わる）も合わせると、**別のことをしていても「終わったよ／手を貸して」と向こうから呼び戻してくれます**。放置監視にぴったりです。

![各セルヘッダの ◀▶ とツールバーの並べ替えトグル](/images/mulmoterminal-grid/05-order.png)

**並び順はディレクトリ側からも指定できます。** `.mulmoterminal.json` に `orderPriority` を書くと、その数字の小さい順にセルが並びます（書いていないディレクトリは従来どおり）。「本番リポは必ず左上」を固定できます。

### 通知音は finished と waiting で分けられます

以前は「終わった」も「呼ばれている」も同じ音でした。いまは**種類ごとに別の音**にでき、**それぞれ個別に ON / OFF** できます（プリセット同梱なので、音源ファイルを自分で用意する必要はありません）。

「完了では鳴らさない。呼ばれた時だけ鳴らす」ができるので、**並列数を増やしても通知に溺れません**。

同時に、**サブエージェントが終わったときにメインがまだ動いているのに「呼ばれている」通知が飛ぶ**不具合も直りました。サブエージェントを多用する長い作業で誤報の連続になっていたやつです。

## 6. キーボードだけでグリッドを操る

**拡大とグリッドの行き来を、マウスに持ち替えずにやれます。**

`~/.mulmoterminal/config.json` の `keymap` にキーを割り当てます。

```jsonc
{
  "keymap": {
    "zoom-toggle": "F1",
    "next-attention": "F2",
    "zoom-next": "PageDown",
    "zoom-prev": "PageUp",
    "terminal-new-adjacent": "F3"
  }
}
```

割り当てられるアクションは9つ。

| アクション | 動き |
|---|---|
| **`zoom-toggle`** | 拡大 ↔ 折りたたみ。**カーソルのあるターミナル**が拡大され、戻ってもカーソルはそこに残る（往復で位置を見失わない） |
| **`next-attention`** | **見るべき次のターミナルへ**。要対応 → 完了して未レビュー → idle の順で、**ターン実行中のものは飛ばす**。端で止まらず巡回する |
| `zoom-next` / `zoom-prev` | 画面上の並び順に拡大対象を送る |
| `terminal-new` | 新しいターミナル |
| **`terminal-new-adjacent`** | **隣に作って、そのディレクトリを引き継ぐ**（グリッドで「分割」に一番近い操作） |
| `terminal-close` | 閉じる |
| `copy` / `paste` | コピー・ペースト |

`next-attention` が個人的に一番効きます。**押すたびに「自分待ち」を渡り歩く**ので、9セルを目でスキャンする作業が消えます。

:::message
**既定のキー割り当ては、意図的にありません。** バインドしたキーは、ターミナルの中で動いているプログラムに届かなくなります。そのトレードオフを決められるのは使う人だけなので、`keymap` を書くまでショートカットは OFF です。

書き間違えると**サーバが起動せず、該当行を表示して止まります**。黙って無視されると「効かないショートカット」と見分けがつかず、アプリの中を探し回ることになるからです。

**Settings → Keyboard shortcuts** に、割り当て済みも未割り当ても含めて全アクションが並びます（そもそもどんなアクションがあるかは、ここでしか分からないので）。
:::

## 7. ファイルを見る・直す

ターミナルに出たファイルパスを**クリックすると、そのターミナルの隣にファイルが開きます**。拡大中でも、グリッドでも、開いた場所の隣です。

- コードはエディタ、`.md` はレンダリング済みビューへ、と**拡張子でルーティング**
- **ページをリロードしても開いたまま**
- **保存が、同じファイルを編集したエージェントを踏み潰さない**ようになっています（ディスク上で変わっていたら、保存前に知らせます）
- エディタが触ったファイルは**3世代ぶん**残ります

「エージェントの出力を読んで、READMEだけ自分で直す」がグリッドから出ずに終わります。

## ＋α：`.mulmoterminal.json` でセルごとに色・名前・音を変える

グリッドにセルが増えてくると「どれがどのプロジェクト？」となりがちです。そこで、**各プロジェクトのディレクトリに `.mulmoterminal.json` を置く**と、そのディレクトリで開いたターミナル（＝そのセル）だけ、**バッジ名・色・テーマ・端末パレット・通知音**を個別にカスタムできます（アプリ全体のテーマはそのまま）。

![ディレクトリごとに背景色とバッジを変えたグリッド](/images/mulmoterminal-grid/06-dircolors.png)

たとえば本番リポは 🔥 赤、ステージングは 🧪 シアン、実験は 🚀 紫…と染め分ければ、ひと目でどのセルが何か分かります。設定ファイルはこれだけ:

```jsonc
{
  "name": "PROD · payments",            // ヘッダーに出るバッジ名
  "badgeColor": "#cf222e",              // バッジ色（#rrggbb）
  "headerColor": "#450a0a",             // セルのヘッダ背景
  "cellBorderColor": "#cf222e",         // 枠線
  "theme": "nord",                      // 端末パレット: midnight | nord | daylight | solarized
  "colors": { "background": "#190a23", "cursor": "#ff2e63" }, // 個別の上書き
  "fontSize": 16,                       // このディレクトリだけ文字を大きく（8〜32・既定14）
  "fontFamily": "'JetBrains Mono', monospace",  // 日本語を出すなら CJK 対応フォントを
  "orderPriority": 0,                   // 小さいほど前。本番リポを常に左上に固定できる
  "provider": "openrouter",             // このディレクトリのセッションが使うバックエンド
  "model": "z-ai/glm-5.2",              // モデルもディレクトリ単位で
  "sound": "./.mulmoterminal/alert.mp3" // このディレクトリの通知音（相対パス）
}
```

全項目オプションです。本番リポは赤バッジ＋専用の警告音、実験用は別の色…と分けておけば、**セルを見た瞬間にどのプロジェクトか分かり、音でも聞き分けられます**。

**ファイルを保存すると、リロードなしでその場で反映されます**（ページを開き直す必要はありません）。

なお `fontSize` は Settings のステッパーからも変えられ、そちらは**ブラウザごとに記憶**されます。スマホとデスクトップで同じサーバを見ても、それぞれのサイズを保てます。ブラウザのズームで代用しないでください——xterm のグリッドとシェルが幾何を取り違えて、カーソルと折り返しがずれます。

書き方が分からなくなったら、Claude Code に **`/mulmoterminal-config`** と打つと、対話でこのファイルを作ってくれます。

## おまけ

- **二重オープン警告**：別セルで開いているセッションを resume しようとすると確認が出ます（取り違え防止）。
- **GitHub クイックリンク**：セルのリポジトリの Repo / Issues / PRs をヘッダーから直接開けます。

## まとめ

MulmoTerminal のグリッドビューは、

1. 自動レイアウト＋タブで**最大81セッションを一望**
2. 各セルが**本物の Claude / Codex セッション**（裏でも走り続ける）
3. **worktree 分離**で1リポジトリを安全に並行作業＋セル内 PR
4. 拡大すると**コックピット・ロスター**——全員の進捗が文字で読める
5. **Auto 並べ替え＋状態可視化＋種類別の通知音**で放置監視できる
6. **キーボードだけ**で拡大・巡回・新規作成まで完結
7. ターミナルのファイルパスを**クリックして隣で開いて直せる**

という構成で、**「AI エージェントを何体も同時に回す」** ための運用画面になっています。しかも動かしているのは本物の対話 `claude`。だから **何体並列に回しても料金はいつもの Claude サブスクの枠内**（プラン利用の範囲）で、終わったら音で呼び戻してくれます。
